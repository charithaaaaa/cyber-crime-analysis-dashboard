# cyber-crime-analysis-dashboard

## 📊 Overview
This project presents an interactive Power BI dashboard analyzing cyber crime trends across major Indian cities. The goal is to identify high-risk locations and dominant cyber crime categories to support data-driven policing.

## 🛠 Tools Used
- Power BI
- Power Query
- Excel

## 🔍 Key Features
- KPI showing total cyber crime cases
- Top 10 hotspot cities analysis
- Top 10 cyber crime categories
- Data cleaning and transformation using Power Query
- Top-N filtering for focused insights

## 📁 Files in Repository
- `.pbix` file — Power BI dashboard
- `dashboard.png` — dashboard preview

## 🚔 Use Case
This dashboard demonstrates how data analytics and visualization can support cyber crime monitoring and evidence-based policing.
